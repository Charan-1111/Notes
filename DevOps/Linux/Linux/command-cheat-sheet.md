| Command   | Description |
| -------- | ------- |
| echo | Prints the content to the console    |
| history | Let's us see the history of all the commands that we used |
| clear | Clears the terminal |
| pwd | Prints the current working directory path |
| ls | Lists the content present in the current directory |
| cd \<file-path\> | Change directory to the given file-path |
| cd .. | Changes the directory to one parent above in backward direction |
| cd ../.. | Changes the directory to n parents |
| cat \<file-name\> | Prints the contents of the file to console |
| head -n \<n\> \<file-name\> | Prints the first n lines of the file |
| tail -n \<n\> \<file-name\> | Prints the last n lines of the file |
| more \<file-name\> | Prints the content of the file but not whole |
| less \<file-name\> | Prints the content of the file but not whole |
| less -N \<file-name\> | Prints the content of the file but not whole, along with the line numbers |
| touch \<file-name\> | Creates a file if not exits |
| mkdir \<directory-name\> | Creates a new directory inside the current directory |
| move | Moves a file from one location to another location |
| rm \<file-name\> | Removes the file |
| rm -r \<directory-name\> | Removed the directory and its contents recursively |
| cp source.txt destination/ | Copies the contents from one location to another location |
| cp -R source_dir dest_dir | Copies the contents of the source directory to destination directory recursively |
| cd ~ | Directly takes to home directory |
| ~ | Alias for the home directory |
| grep "hello" file.txt | Prints every line in file.txt that matches word hello |
| grep "search-ward" \<file1\> \<file2\> | Searchs in the multiple files |
| grep -r "search-ward" . | Searches in the entire current directory and all of it's sub-directories |
| . | alias for the current directrory |
| sudo | superuser do, let's us run commands as superuse |
| chmod | Changes the permissions of a file or directory |
