# Notes

This repository is a personal knowledge base for software engineering concepts and deep-dive notes across multiple domains. It is organized to help document and revisit important ideas related to Go, AI, DevOps, and system design.

## Purpose

The goal of this repository is to collect structured notes, explanations, and practical learning material that cover:

- Go language internals and concurrency patterns
- AI and LLM-related concepts
- DevOps and Linux fundamentals
- Distributed systems and system design principles
- Networking, reliability, scaling, and architecture topics

## Repository Structure

### 1. Go Lang
The Go notes cover core language concepts, concurrency, runtime behavior, and practical design patterns.

Key topics include:

- Channels and goroutine communication
- Context propagation and graceful shutdown
- Go scheduler behavior
- Mutexes, RWMutex, WaitGroup, and sync primitives
- Race conditions and race detector
- Error handling and custom error patterns
- Methods, types, packages, and modules
- Selects, timeouts, and cancellations

Relevant folder:

- [Go Lang](./Go%20Lang)

### 2. AI
This section contains notes focused on artificial intelligence concepts and LLM-related learning.

Relevant folder:

- [Ai](./Ai)
- [Ai/LLM's](./Ai/LLM's)

### 3. DevOps
This area focuses on operational and infrastructure concepts, especially Linux-based systems and engineering workflows.

Relevant folder:

- [DevOps](./DevOps)
- [DevOps/Linux](./DevOps/Linux)

### 4. System Design
This section contains architecture and distributed systems notes covering core design trade-offs, networking, and reliability.

Key topics include:

- CAP theorem and consistency
- DNS fundamentals
- Load balancing concepts
- Reverse proxy and proxying patterns
- SLI, SLO, and SLA
- TCP/UDP networking
- TLS and HTTP
- Elasticsearch and search systems
- Latency, throughput, and availability
- Low-level design practices

Relevant folder:

- [System Design](./System%20Design)
- [System Design/Low Level Designs](./System%20Design/Low%20Level%20Designs)
